Product Requirements Document (PRD)
AI Career Agent — Personalized Job Discovery & Application Platform

Version: 1.0
Status: Product Definition
Product Type: AI-powered SaaS
Primary Users: Students, fresh graduates, and early-career professionals
Initial Market: India, with international jobs as a later expansion
Core Principle: Find fewer, better opportunities and help the user apply intelligently.

1. Executive Summary

AI Career Agent is a personalized job and internship discovery platform that continuously searches multiple job sources and identifies opportunities that closely match a user's resume, skills, experience, preferred roles, location, and compensation requirements.

Instead of presenting users with hundreds of generic job listings, the platform uses a combination of:

structured filtering
semantic search
skill matching
requirement classification
resume-job similarity
personalized ranking
resume gap analysis

to determine which opportunities are worth the user's attention.

For each high-quality opportunity, the system explains:

Why the candidate is a good match
What requirements are missing
Which missing requirements are mandatory vs preferred
Which skills are transferable
How the resume could potentially be improved
Whether the system recommends applying

The user can update their resume/profile if necessary and must explicitly confirm before an application is submitted.

The platform is designed as a scalable SaaS, while the initial implementation prioritizes free/public APIs, open-source models, caching, and low-cost infrastructure.

2. Vision
Vision Statement

Build an AI career agent that continuously finds the opportunities a candidate is most likely to succeed in, explains why, improves application readiness, and keeps the candidate in control of every application.

The long-term goal is not to become another job board.

The goal is to become the user's personal career agent.

5. Product Principles
P1 — Relevance over volume

The system should optimize for quality of recommendations, not number of jobs.

P2 — Explainability

Every recommendation should have an understandable explanation.

P3 — Human control

No application is submitted without explicit user approval.

P4 — Truthfulness

The AI must never fabricate candidate experience, skills, projects, certifications, or achievements.

P5 — Cost efficiency

Use free/public APIs and open-source models wherever practical.

P6 — Privacy

Resume and application data must be treated as sensitive information.

P7 — Source independence

The system must not depend on a single job provider.

13. Initial Job Sources
13.1 Adzuna

Adzuna provides a REST API for searching job advertisements by country, keyword and location and exposes job-search and salary-related endpoints. It requires an app_id and app_key.

Role: Broad job discovery.

13.2 Greenhouse

Greenhouse's public Job Board API exposes published jobs through unauthenticated GET endpoints. It can provide job descriptions, departments, offices and application-related information.

Role: Direct company-level job discovery.

13.3 Lever

Lever provides a public postings API for published jobs, including paginated job listings and individual postings. It also supports programmatic applications for appropriate integrations, although the initial product should not depend on that capability.

Role: Direct company-level job discovery.

13.4 Additional sources

21. Initial Matching Formula
Match Score =

30% Skill Match
25% Semantic Similarity
15% Experience Fit
15% Preference Fit
10% Role Alignment
 5% Education / Other

The weights must be configurable.

60. Final Product Definition
Working product statement

AI Career Agent is a personalized career automation platform that continuously discovers jobs and internships from multiple sources, evaluates each opportunity against a candidate's resume and preferences, explains the candidate's strengths and gaps, helps optimize the application, and requires explicit user approval before applying.

The product loop
          ┌──────────────────────────────┐
          │                              │
          ▼                              │
     FIND OPPORTUNITIES                  │
          │                              │
          ▼                              │
     UNDERSTAND FIT                     │
          │                              │
          ▼                              │
     IDENTIFY GAPS                      │
          │                              │
          ▼                              │
     IMPROVE APPLICATION                │
          │                              │
          ▼                              │
     USER CONFIRMS                      │
          │                              │
          ▼                              │
        APPLY                            │
          │                              │
          ▼                              │
     TRACK OUTCOME                      │
          │                              │
          ▼                              │
     LEARN FROM RESULT ─────────────────┘

That loop is the actual moat.

The individual components—job APIs, embeddings, LLMs, resume parsing—can all be replicated. The long-term advantage comes from building a candidate-specific feedback loop where the system learns which opportunities actually turn into interviews and offers.

And for V1, I would keep the stack deliberately lean: Next.js + FastAPI + PostgreSQL/pgvector + Redis + Docker + open-source embeddings + a small set of public job sources (starting with Adzuna, Greenhouse, and Lever). Greenhouse's public GET endpoints don't require authentication, while Adzuna requires developer credentials and Lever exposes published postings through its postings API.
